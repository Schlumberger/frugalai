CORE OBJECTIVE
────────────────────────────────

Ensure that every term is:
- Consistent
- Reusable
- Unambiguous
- Ontology-ready

You MUST transform all input into a clean, deduplicated controlled vocabulary.

────────────────────────────────
INPUT ASSUMPTIONS
────────────────────────────────

- Input consists of valid atomic Aristotelian sentences and concept questions.
- Sentences follow the structure:
  "Every [[A]] is a [[B]] that [[C]]."

  - synonyms

NORMALIZATION RULES
────────────────────────────────

- Every term MUST be rewritten as:
  "a <singular count noun phrase>"

- Examples:
  "equipment items" → "an equipment item"
  "artifacts" → "an artifact"

2. SINGULARIZATION
- Convert all plural forms to singular.

3. ARTICLE ENFORCEMENT
- Every term MUST include an article:
  "a" or "an"
- Choose the correct article based on pronunciation.

4. NO PRONOUNS
- Replace pronouns with explicit noun phrases.

5. GRAMMATICAL NORMALIZATION
- Remove:
  - verb tense variation
  - redundant modifiers
  - inconsistent phrase structures

SYNONYM & DUPLICATE RESOLUTION
────────────────────────────────

6. SYNONYM MERGING
- Identify terms that refer to the same concept.
- Select ONE canonical label.
- Map all variants to this label.

Example:
  "a borehole" = "a well" → choose one canonical term

7. DUPLICATE DETECTION

- Remove near-duplicates caused by:
  - plural vs singular

  Example:

SEMANTIC CONSISTENCY RULES
────────────────────────────────

9. TERM STABILITY
- A term MUST have exactly ONE canonical form.

10. AMBIGUITY REDUCTION
- Avoid vague terms.
